Vision benchmark: same pieces, a better detector.

A YOLOv8m chess piece detector was fine-tuned on synthetic RGB scenes built from one exact mesh set, ezeeone_Dubrovnik_1960_set_02_stls. This page reports recorded, static model predictions — no live inference, no camera, no upload.

Synthetic RGB scenes · Known board corners · Piece detector only

Evaluation set

Metrics are computed on the full selected dataset and do not change when the example preview below is filtered.

How the metrics are defined
  • Joint accuracy = piece colour + type both correct, over the ground-truth occupied squares (denominator = GT occupied squares, not 64).
  • Mismatches / misses count wrong class or empty prediction on a GT occupied square; spurious detections on GT-empty squares are counted as occupancy errors.
  • Exact board = all 64 squares match the ground truth exactly (including empty squares).
  • Timing covers preprocessing + GPU inference + square mapping, and excludes image I/O, camera capture and board-corner detection. Hardware: RTX 5070 Laptop 8 GB.

    Dataset and method
    
    
    
      Training data: 3,000 synthetic RGB images covering
      375 distinct board positions (8 views per position). The positions were split
      by board position — not by image — into 2,096 train,
      448 validation and 456 test images. Three old mesh layouts
      were excluded from training so the model could not memorise them.
    
    
    
    
      Model: YOLOv8m initialised from ChessReD2K weights, fine-tuned for
      15 epochs with AdamW; training loss combines
      CIoU + BCE + DFL. Scenes are rendered procedurally in VTK with
      50 mm squares and a 78 mm king, with no board
      dynamics.
